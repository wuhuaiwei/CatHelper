# 更新记录

## v1.1.0 · 2026-10-18

### 伙伴与对话

- 支持大 / 中 / 小三种伙伴图标大小，设置保存后可立即调整。
- 气泡消息可选字复制，标题和空白处可拖动小猫与对话框。
- Enter 发送，Ctrl+Enter / Shift+Enter 换行，并检查输入法组词状态。
- 修复长消息被当作整行滚动、一次跨过大量文字的问题；改为限幅像素滚动。
- 阅读历史时保留当前位置，不再被新消息或消息排版强制拉到底部。
- 打开设置时暂时隐藏气泡，关闭后恢复显示状态与草稿。

### 设置与外观

- 奶油紫圆角窗口、自定义标题区、细边框、关闭按钮与缩放手柄。
- 切换默认 AI 后仅展示对应的程序与模型设置，保留各自配置。
- 模型改为异步加载的下拉框，未配置、加载中或失败时置灰。
- 浏览按钮与输入框等高，说明文字改为悬浮提示。
- 设置、日志窗口与资源管理器菜单使用统一猫咪图标。

### 安装与文档

- 提供 Windows x64 中文 EXE 安装器，内含 Python / Tkinter。
- 安装版数据保存到用户目录，升级与卸载均保留。
- 补充下载入口、操作示意图、详细使用指南与排错说明。
- 构建脚本运行测试并生成安装器 SHA256 校验文件；版本号可通过参数指定。
